# Student Information System

A simple Python program used for a **Collaborative Code Management** GitHub exercise.

## Aim

Developers work on separate feature branches, submit pull requests, and have their contributions reviewed and merged into the shared `main` branch. They then synchronise their local copies of `main`.

## Run the program

```bash
python main.py
```

## Working rules

- The instructor allocates one numbered section of `main.py` to each developer. The number is a task slot, not necessarily the student's class number.
- Change **only the existing `print()` statement** in your allocated section. Keep its label, and do not change other lines, comments or spacing.
- Use fictional personal information. Course and finance values should be agreed with the instructor.
- Work on a uniquely named branch, push it to this repository, and create a pull request targeting `main`.
- Do not merge your own pull request. Wait for the instructor to review and merge it.
- Once the instructor announces that merging is finished, run `git switch main` and `git pull origin main` in VS Code to receive the combined program.

## Note

Unallocated sections may remain `Not completed`. This is expected when fewer than 11 developers attend. The exercise is about Git collaboration rather than a complete student-record application.
